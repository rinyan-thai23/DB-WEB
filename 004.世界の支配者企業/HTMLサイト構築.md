# Project: World Dominators Database (Direct HTML Build)

## 1. プロジェクト概要
提供されたCSVデータ (`007.世界の覇者・黒幕たちの『思考アルゴリズム』データベース - Sheet1.csv`) を元に、**静的なウェブサイト（HTML/CSS）** を構築します。
Python等のスクリプトは使用せず、**AIエージェントが直接HTMLコードを書き、ファイルを作成**してください。

## 2. 作業範囲（重要）
トークン制限と品質保持のため、今回は**「フェーズ1」**として以下の範囲のみ作業を行ってください。

1.  **共通リソース作成**: `style.css` (デザイン定義)
2.  **トップページ作成**: `index.html` (一覧ページ)
3.  **詳細ページ作成（先行10件のみ）**: CSVの **上から10行分（CODE-001 ～ CODE-010）** のHTMLファイルを個別に作成。

**※ 注意: 11件目以降はまだ作成しないでください。**

## 3. ディレクトリ構造
以下の構造でファイルを作成してください。

/project-root
├── style.css             # 共通スタイルシート（サイバーパンク/ターミナル風）
├── index.html            # トップページ（全100件へのリンク一覧。ただし11以降は空リンクでOK）
└── pages/                # 詳細ページ格納フォルダ
├── CODE-001.html
├── CODE-002.html
├── ...
└── CODE-010.html


## 4. デザイン要件 (Cyberpunk / Database Style)
「機密政府データベース」のようなデザインにしてください。
- **背景**: 黒 (#050505)
- **文字色**: ターミナルグリーン (#00ff41) または アンバー (#ffb000)
- **フォント**: 等幅フォント (Monospace)
- **装飾**: 枠線、スキャンライン、点滅カーソルなどの演出。

## 5. データマッピング指示
CSVの各カラムを以下のようにHTMLに埋め込んでください。

### 詳細ページ (`pages/CODE-XXX.html`)
各ファイルは以下の構成にしてください。
- **ファイル名**: `ID` を使用 (例: `CODE-001.html`)
- **Header**: パンくずリスト (`Index > CODE-001`)
- **H1 Title**: `対象 (Entity)`
- **Subtitle**: `コードネーム`
- **Badges**: `支配領域 (Domain)`, `依存クラス` (クラスごとに色を変える S=赤, A=橙, B=青)
- **Code Block**: `支配アルゴリズム` を `<pre><code>` タグで表示
- **Main Content**: `観察ログ (Log)` を読みやすく表示
- **Footer**: `チョークポイント` を警告枠として表示。トップページへの戻るボタン。

### トップページ (`index.html`)
- テーブル、またはカードレイアウトで、`ID`、`対象 (Entity)`、`コードネーム` の3つを表示。
- リンク先は `pages/CODE-XXX.html` とする。

## 6. 実行プロセス
1.  まず `style.css` を作成する。
2.  次に `index.html` を作成する（CSVデータを元にリスト化）。
3.  最後に `pages/` フォルダを作成し、CSVの1行目から10行目までのデータを読み取り、それぞれHTMLファイルとして出力する。
